Keep (1, 10, 100) as the default. Opt in to a larger limit for dense scenes.

What is being limited?

The highest-confidence predictions per image and category enter matching. Ground truths stay uncapped. Ten classes of 100 stars each therefore fit the default; class-agnostic evaluation merges them into one capped class.

Changing the cap changes the metric. Label custom AP separately from standard COCO AP@100.

Reproduction, controls & precedent

A deterministic connected-component toy detector reads the rendered pixels. It uses no labels, weights or hosted inference. The miss control deliberately removes every tenth prediction. Raising the cap does not recover missed objects.

Python evaluates 20 scenes/controls with released and patched Supervision in separately pinned uv environments. All 80 evaluations agree with pycocotools at the same cap. JavaScript only displays those measured results.

COCO AP samples 101 recall points; the default result for 1,000 perfect boxes is 11/101 ≈ 10.89%, rather than exactly 10%.

Existing configurable limits: pycocotools maxDets · TorchMetrics max_detection_thresholds · RF-DETR eval_max_dets.
